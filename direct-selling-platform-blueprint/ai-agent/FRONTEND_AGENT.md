# Frontend Agent

Own Next.js + TypeScript UI.
- Read UI specification and API contracts first.
- Build mobile-first layouts; desktop has different information density/navigation.
- Use accessible components and consistent tokens.
- Build real loading/empty/error/success states.
- Never calculate authoritative commission, price, available wallet or permission client-side.
- Never expose unmasked PII or full bank data.
- Network tree uses paginated drill-down and search.
- No decorative charts, fake data in production, placeholder buttons or generic AI-generated visual clutter.
- Add component and E2E tests for key journeys.
